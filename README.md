# Low Tide

A first-person narrative exploration game for PC, made in **Godot 4.4** (GDScript).

January 1998. You are Arthur, the winter keeper of Gannet Rock Light Station, a small island off the coast of Maine. The tide decides where you can walk. The only other voice is Clara, a Coast Guard dispatcher on VHF channel 16. You have seven days.

All seven days and all three endings are implemented. The game is still in development: the writing is first-draft quality, and all audio is generated in code (see [Status](#status)).

## What is in the game

- **Seven days.** Each day has a morning (stove, barometer, tide table, wind the weights, radio check-in with Clara), an expedition (cross the sandbars while the tide allows, with binoculars and a pocket watch), and an evening (light the lamp, write the log, call Clara, sleep).
- **The tide is the level design.** A continuous tide model. Low water arrives about 50 minutes later each day. Sandbars close when the water passes 2.1 m. Depth slows you and, if it gets too deep, sweeps you back to the dock. Day 4 is a storm that keeps the range high. Day 5 is a spring low (-0.4 m) that opens the south reef and the causeway.
- **A radio that never pauses the game.** Clara calls on channel 16, sometimes with priority calls. You answer with two choices while you keep moving. Your answers move a hidden Trust value, and what you report or withhold changes what she tells you.
- **Story objects.** Six cassette tapes, a satchel and a keeper's journal (log, satchel, tapes), bell buoys, a hydrophone, and landmarks: the wreck, the west sea cave, the north cove and the south reef vault.
- **Three endings:** *The Right Address*, *Left Quiet* and *On the Record*.
- **Opening.** A title screen with a live view of Gannet Rock at dusk (New watch, Continue the watch, Settings, Quit). New watch plays a prologue of typed fragments from Arthur's year, with choices that set backstory and starting trust, intercut with the tender's crossing in dawn fog. A setup tutorial then lists the controls for keyboard and gamepad before Arthur steps onto the island.
- **Diegetic interface.** A pocket watch, a paper tide table, painted tide marks on the dock pilings and the journal. An assist readout can be switched on in settings.
- **Systems.** Autosave and Continue, a pause menu, and full settings: graphics presets (including a Steam Deck preset), audio buses, lighting, remappable keyboard and gamepad bindings, and accessibility options (assist readout, reduce motion, UI and subtitle scale).
- **Look and sound.** A painterly look: painted sky with sun path and moon, layered colour fog, a Gerstner sea with shoreline foam, and a different weather for each day (fog, overcast, dense fog, storm, clear, cold and clear, dawn haze). Models, materials and textures are generated by scripts in `tools/` and committed. Sound is synthesised at startup: foley, sea and wind beds, an adaptive score that arrives in swells and recedes into the sea (it can be set to stings only in settings), and procedural music stings for the endings and key moments.

## Status

Work in progress. Be aware of the following:

- The writing, including the prologue, is first-draft quality and is expected to get a polish pass. All of it is editable text in `dialogue/dialogue.json` and `story/`.
- There are no audio asset files. Every sound is generated in code.
- Radio lines are text with a procedural squelch. There is no voice acting.
- Not implemented: localisation, achievements, cloud saves and Steam integration.
- The Unity port in `unity/` is parked. The Godot project is the reference build.

## Run it

1. Install **Godot 4.4** (the standard build, not .NET). Tested with 4.4.1.
2. Open `project.godot` in the Godot editor (the first open imports the assets) and press **F5**. The main scene is `main.tscn`. The game starts on the title screen.

The project uses the Forward+ renderer, so it needs a Vulkan-capable GPU. Export presets for Windows Desktop and Linux / Steam Deck are in `export_presets.cfg`.

Progress is saved to `user://lowtide_save.json` at the start of each day and at wait anchors, and **Continue** on the title screen resumes from it. Settings are in `user://lowtide_settings.cfg`. Endings you have seen are kept in `user://lowtide_endings.json`.

## Controls

Every binding can be changed in **Settings > Controls**.

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | W A S D | Left stick |
| Look | Mouse | Right stick |
| Brisk walk (uses stamina) | Shift | Left stick click |
| Inspect / use (hold to wind or light) | E | A |
| Binoculars | B or right mouse button | Left trigger |
| Pocket watch | Q | Left bumper |
| Radio reply 1 / 2 | 1 / 2 | D-pad left / right |
| Dismiss radio | X | B |
| Journal | Tab | Back / View |
| Assist readout | F1 | Y |
| Pause | Esc | Start |

Binoculars, the pocket watch and the hold-to-use action can each be switched from hold to toggle in settings. Holding Esc (or B) skips the prologue. In debug builds, **T** skips time.

## Tests

The suite is a custom headless runner (`tests/run_tests.gd`). It covers the tide model and depth bands, the clock, dialogue conditions, saves, the typography rule and a simulation of the whole week.

```bash
GODOT=/path/to/godot tools/run_all_tests.sh
```

`run_all_tests.sh` runs three steps: the Godot suite (must report `N checks, 0 failures`), a check that the fixtures in `unity/Fixtures` are up to date, and the C# parity tests for the parked Unity port. If you have no .NET SDK, skip the last step:

```bash
SKIP_DOTNET=1 GODOT=/path/to/godot tools/run_all_tests.sh
```

To run only the Godot suite, use `tools/run_tests.sh`.

## Screenshots and dev tools

- `tools/shots.sh <outdir> [filter]` renders the art vantages from `tests/screenshot.gd` to PNGs. It needs a display or xvfb. On a machine without a GPU, set `LAVAPIPE=1` to use the software Vulkan driver.
- `tests/ui_shots.gd` renders every boxed UI surface over a game frame at 1280x720 and 1280x800.
- `tests/perf.gd` reports triangles and draw calls per vantage for a quality preset.
- `tools/build_assets.sh` rebuilds the generated textures, materials, models and scenes.

## Repository layout

| Path | What is in it |
|---|---|
| `main.tscn`, `main.gd` | Entry scene: builds the world, the player and the interface |
| `autoload/` | Global singletons: game clock, tide system, game state, day director, saves, radio, audio director, tape player, reactive director, settings |
| `story/` | Day data, conversations, conditions, items, log entries, endings and the prologue |
| `dialogue/` | `dialogue.json`: every radio line, tape and ending text |
| `world/` | Terrain, island, interiors, ocean, bell buoys, hydrophone, interactables |
| `art/` | Sky rig, atmosphere, weather looks, painterly shaders |
| `scenes/` | Generated island and interior scenes |
| `assets/` | Fonts, generated materials, models and textures |
| `player/` | First-person controller |
| `ui/` | HUD, title screen, prologue player, menus, settings menu, pocket watch, theme and fonts |
| `audio/` | Procedural synthesis for foley, sea and wind, the score and music stings (there are no audio files) |
| `tests/` | The headless test suite and the screenshot, UI and perf tools |
| `tools/` | Test runners, asset generators, fixture and audio exporters |
| `docs/` | Design and production documents (below) |
| `unity/` | Parked Unity port of the game logic, with its own README |
| `reference/` | The original single-file HTML prototype, kept read-only |
| `marketing/` | Steam store page draft, logo and brand kit, screenshots |
