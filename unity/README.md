# Low Tide: Unity project

Final build target: **Unity 6 LTS (6000.0.x), Universal Render Pipeline, C# 9**.
The Godot project at the repository root is the reference implementation (see `docs/unity_port_plan.md`).

## State
- `Assets/Scripts/Core`: engine-free game logic, fully ported and **verified against the Godot build** (27 fixture-parity tests, `dotnet test`).
- `Assets/Tests/EditMode`: NUnit parity tests (the same files are compiled by `unity/dotnet/Tests`).
- Game layer (world, player, UI, audio): **not written yet** (stages U2-U6).
- `ProjectSettings/` holds only `ProjectVersion.txt`; Unity generates the rest when the project is first opened. **This project has not yet been opened in Unity**, so the package versions in `Packages/manifest.json` are unverified.

## Open it
1. Unity Hub: *Add project from disk*, pick this `unity/` folder, choose any installed Unity 6000.0.x editor (the pinned version in `ProjectVersion.txt` is a placeholder).
2. After first import, commit the generated `ProjectSettings/*` and `Packages/packages-lock.json`.

## Run the tests
- No editor needed: `dotnet test unity/dotnet/Tests/LowTide.Core.Tests.csproj`
- In Unity: *Window > General > Test Runner > EditMode*. From the command line:
  `Unity -batchmode -nographics -projectPath unity -runTests -testPlatform EditMode -testResults results.xml`

## Shared data
`dialogue/dialogue.json` (repo root) is the source of truth. Run `tools/sync_unity_data.sh` after editing it. Fixtures in `Fixtures/` are generated by Godot; regenerate with `godot --headless -s tools/export_fixtures.gd` and never edit them by hand (`Fixtures/spec.json` is the hand-authored input).
